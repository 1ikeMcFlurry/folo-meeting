# Folo 会议 Android 界面

第一版原生 Android，配置前后使用 BLE，会中不连接。用户在会后整理最终纪要。

色彩：纸面白 #FFFFFF、浅蓝灰背景 #F6F8FC、正文 #203048、辅助文字 #64748B、主操作蓝 #275DAD、分隔线 #DCE3ED。
字体：Android sans 正文，sans-serif-medium 标题；标题 30sp、章节 21sp、正文与编辑 17sp、辅助 14sp。
布局：单列左对齐，底部三个入口「设备 / 记录 / 服务设置」。编辑器以整页可读文本为主，云端原稿通过独立查看入口读取。

```
Folo 会议
记录

会议日期与用户标题
处理状态
────────────────
下一场会议

设备          记录          服务设置
```

不使用假会议、假电量或演示成功状态填充页面。录音开始必须解释蓝牙将断开；设备屏幕是录音状态依据。
录音文件不进入手机；文字原稿、编辑稿与凭证存储在 Android Keystore 加密的应用私有空间，禁止备份。
编辑页和账号页开启防截图，开发验证只截图无敏感信息的设备页。

## 飞书完整记录排版

沿用飞书原生阅读样式：文档标题只出现一次，二级标题划分会议信息、纪要与待办、逐字稿。会议信息用短列表，正文保持左对齐；发言人和相对时间加粗，下一段放发言内容，说明使用引用样式。不把长逐字稿塞入横向表格，也不虚构结论或待办。

手机提供原生滚动预览，标题 21sp、正文 16sp，按同一套块模型渲染。超过 120 段时明确标注预览范围，发布仍包含全部内容。预览继承编辑内容防截图要求。
