# CW2017 4.2V 520mAh Profile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the supplied 80-byte `4.2v_520mah` CW2017 profile and select it as the firmware default without deleting the existing profile.

**Architecture:** Keep the profile table as the single source of battery calibration bytes and keep selection in `board_config.h`. Add a host-compiled contract test that includes the real production headers and compares all 80 bytes literally.

**Tech Stack:** C11, CW2017 BATINFO table, host `cc`, ESP-IDF 5.5.3.

## Global Constraints

- Preserve `CW2017_PROFILES[0]` unchanged.
- Add `CW2017_PROFILES[1]` with the exact name `4.2v_520mah`.
- The new data must contain exactly 80 bytes corresponding to registers `0x10` through `0x5F`.
- Set `CW2017_PROFILE_SEL` to `1`.
- Do not modify SOC smoothing, alert thresholds, UI mapping, or profile write/restart logic.
