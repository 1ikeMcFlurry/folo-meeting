# CW2017 4.2V 520mAh 电池参数设计

## 目标

将用户提供的 80 字节 CW2017 BATINFO 参数作为新的默认电池 profile，同时保留现有参数以便回退。

## 设计

- 保留 `CW2017_PROFILES[0]` 现有 `ytl_520mah_moby5500` 参数。
- 新增 `CW2017_PROFILES[1]`，名称为 `4.2v_520mah`。
- 新 profile 数据严格按用户提供的 80 个十六进制字节排列，对应寄存器 `0x10` 至 `0x5F`。
- 将 `board_config.h` 中 `CW2017_PROFILE_SEL` 从 `0` 改为 `1`。
- 不改变 CW2017 探测、比较、写入、重启和 UPDATE_FLAG 处理流程。设备启动时若芯片内容不同，现有驱动自动重写 profile。

## 验证

- 测试 profile 数量至少为 2。
- 校验索引 1 的名称为 `4.2v_520mah`。
- 校验索引 1 的长度和全部 80 字节与输入完全一致。
- 校验默认选择为索引 1。
- 执行 ESP-IDF 5.5.3 固件构建。

## 范围外

- 不修改 SOC 平滑算法、告警阈值或电池 UI 映射。
- 不删除旧 profile。
