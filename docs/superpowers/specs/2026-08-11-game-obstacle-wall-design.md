# 游戏障碍物矩形墙设计

## 目标

将三线跑酷游戏中以代码关键字文本显示的障碍物，替换为橙色圆角竖直长方形墙。保持现有移动、生成、计分、冲刺和结束流程不变。

## 外观与布局

- 障碍物使用普通 LVGL 矩形对象，不再使用 `lv_label` 或显示任何单词。
- 固定尺寸为宽 `14px`、高 `72px`。
- 填充色为橙色 `#F59E0B`，通过独立的障碍物颜色常量管理。
- 墙体无文字、无边框，圆角半径为 `5px`，并在其随机所属车道内垂直居中。
- 墙体保持现有从屏幕右侧向左移动的表现。

## 游戏规则

- 沿用现有 5 个障碍对象池、三车道随机生成和 `120px` 生成间距。
- 障碍宽度固定为 `14px`，计分、碰撞和出屏回收均使用该真实宽度。
- 玩家与墙体同车道且横向范围重叠时触发游戏结束。
- 冲刺期间仍保持无敌，可以穿过墙体。
- 得分加速、冲刺时间、冷却时间及菜单文案不在本次修改范围内。

## 实现边界

- 修改 `components/ui/presentation/src/ui_game.c` 中障碍物常量、创建和生成逻辑。
- 删除仅服务于代码关键字障碍的关键字表、语法颜色表和随机文本设置逻辑。
- 不修改公共游戏接口、按键处理、积分持久化或 BLE 行为。

## 验证

- 增加轻量契约测试，确认墙体尺寸为 `14×72px`、颜色为 `#F59E0B`、圆角为 `5px`，且生产代码不再包含关键字障碍表或创建障碍标签。
- 运行契约测试和 ESP-IDF 5.5.3 固件构建。
- 真机验收时确认三条车道内墙体居中、橙色和圆角显示正确、碰撞和冲刺穿越行为正常。
